# Sonidos de trabajo

Sonidos cortos para probar los patches de clase y los de referencia. Descárgalos y guárdalos en una carpeta tuya; si un patch busca un archivo con un nombre concreto (por ejemplo `goldberg.wav`), ponlo en la misma carpeta que el patch.

Para tus encargos, usa sobre todo **tu propio material**: estos son para practicar.

!!! tip "Cualquier formato"
